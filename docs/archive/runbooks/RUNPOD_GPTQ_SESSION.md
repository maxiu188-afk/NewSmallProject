## Completed experiment

The persistent `tmux` session `gptq-f4` ran
`llama2_13b_wikitext2_quarot_w4a4_gptq.json`. Its required sequence is:

1. BF16 reference evaluation on pinned WikiText-2 `test`.
2. GPTQ calibration from pinned WikiText-2 `train` (128 sequences × 2048
   input tokens).
3. QuaRot + symmetric group-128 W4 GPTQ, followed by W4A4 test evaluation with
   K/V retained at 16-bit.

The command completed successfully and wrote its final JSON. The 13B F4 GPTQ
candidate scored PPL `5.837575` versus the same-run BF16 reference PPL
`5.008716`; it used all 128 requested calibration sequences and 280 linears.
The raw files were copied locally and SHA-256 checked before server shutdown.
See `LLAMA2_13B_GPTQ_W4A4_RESULTS.md` for the formal result record.
